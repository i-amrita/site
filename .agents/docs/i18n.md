# i18n

English ships at launch and the static HTML is English. The `?locale=ms|hi|de|ml|en` URL key switches island strings client-side. There are no path-prefixed locale routes; `/about`, `/about.md` and `/llms.txt` stay at the root.

## Pipeline

- Source of truth: `src/i18n/messages/en.json`. Flat keys with a namespace prefix and underscores (`nav_search`, `hero_title`), because Paraglide compiles each key to a function. Values are ICU MessageFormat (`{name}`, `plural`, `select`).
- Targets `ms hi de ml` are filled by `pnpm intl-ai:fill` (config: `intl-ai.toml`, lock state in `src/i18n/messages/intl-ai.lock.d/`, committed). `pnpm intl-ai:check` is the gate (also in lefthook pre-push).
- `project.inlang/settings.json` + `@inlang/plugin-message-format` feed Paraglide. `paraglideVitePlugin` in `astro.config.mjs` compiles to `src/i18n/paraglide/` at dev start and build. That folder is generated and gitignored; never edit or commit it.
- Provider: `[provider] kind = "http"` (OpenAI-compatible). `AI_MODEL_ID` and `AI_API_KEY` come from `.env`; run `set -a; source .env; set +a` before `fill`. `check` needs no env.

## Using it in islands

```tsx
import { m, t, useLocale } from '@/lib/i18n';

function Hero() {
  useLocale(); // subscribes to ?locale= so the island re-renders on change
  return <h1>{m.hero_title()}</h1>;
}
m.keyboard_hint({ key: 'P', action: m.action_projects() });
t(`action_${id}` as MessageKey); // dynamic keys
```

- Call `useLocale()` (or render below a component that does) in every island that shows copy.
- `useLocale()` returns `{ locale, setLocale, locales }`. `setLocale('en')` removes the param.
- The `custom-query` Paraglide strategy (defined in `src/lib/i18n.ts`) reads `?locale=` and falls back to `en`.
- `LocaleSwitch` (default export, self-wrapped in `Providers`) or `LocaleSwitchButton` (inside an existing `Providers`) is the picker.

## Adding a string

1. Add the key to `en.json` (keep keys sorted by namespace).
2. `pnpm intl-ai:fill`, spot-check the output, `pnpm intl-ai:check`.
3. Use `m.key()`. Never hardcode copy in components.

Human edits to a translation are tracked by the lock; run `pnpm exec intl-ai review <key> --locale <l>` to accept them.

## Sandbox

`/dev/i18n?locale=de` (noindex) renders sample keys and the switcher.

## Fonts

Devanagari and Malayalam fall back to system fonts (macOS, Windows, Android ship them). No CDN fonts.
